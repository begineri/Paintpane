# Paintpane icon sources

The Paintpane icon is a gilded pixel frame holding a pixel-art re-drawing of
Vincent van Gogh's *The Bedroom* (1889, Art Institute of Chicago, 1926.417,
artwork 28560, public domain). The AIC image was used only as a reference for
composition and colour; every pixel here is drawn from code, nothing is
resampled from the photograph.

Everything is generated by `export.sh`:

| Output | Size | Drawn by |
| --- | --- | --- |
| `assets-src/installer/Paintpane.ico` | 16, 24, 32, 48, 64, 96, 128, 256 | `icon()` |
| `cmd/spice/spice_windows_amd64.syso` | icon resource from `assets-src/installer/Paintpane.ico` | rsrc v0.10.2 |
| `asset/icons/tray.png` | 118 | `icon(118)` |
| `asset/images/splash.png` | 300 × 300 | `splash()` |
| `asset/images/about_splash.gif` | 600 × 600, ~7.8 s, plays once | `aboutFrames()` |
| `assets-src/installer/Paintpane.bmp` | 240 × 458, Inno Setup wizard panel | `wizardImage()` |

The other file names are kept from upstream because the code and the makefile refer to them.
The installer files live in `assets-src/installer/` next to `Paintpane.iss`.

## Size tiers

Each tier is drawn separately; no size is a downscale of a bigger one.

- **16 / 24 / 32** (`small.go`): hand-placed character grids. Frame plus the
  five strongest blocks: blue-violet wall, green window, yellow bed, red
  cover, orange-brown floor.
- **48 / 64 / 96** (`scene.go`, `detMid`): the shape scene rasterised on a
  1 px grid (96 uses 2 px blocks, i.e. the 48 drawing for 200 % DPI). Adds the
  bed outline with pillow and posts, window bars, table and two chairs.
- **118 / 128 / 256 and splash art** (`detHigh`): adds wall pictures, towel,
  mirror, jug, floor shading. 256 uses 4 px blocks (the 128 drawing at 200 %).

The scene is a list of rectangles and polygons in 0..1 painting coordinates,
each tagged with the lowest tier that draws it. One colour is sampled per
pixel block, so edges stay crisp. Colours live in `palette.go`; the 5 × 7
pixel font for "Paintpane" and the DMG text is in `font.go`; g and p
have two-row descenders so the lowercase p does not read as a capital.

## Editing

1. Change a grid in `small.go`, a shape in `scene.go` or a colour in
   `palette.go`.
2. Run `PREVIEW=/some/dir/preview.png bash assets-src/icon/export.sh` and look
   at the preview sheet (each icon at 1× and zoomed, on dark and light
   taskbar colours).
3. Commit the sources together with the regenerated outputs.

This directory is its own Go module (standard library only) so it stays out
of the app's `go vet ./...` / `go test ./...`.
