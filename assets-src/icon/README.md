# Paintpane icon sources

The Paintpane icon (P19 design "B2 pure blocks", approved 2026-11-15) is a
rounded tile holding the five colour blocks of Vincent van Gogh's
*The Bedroom* (1889, Art Institute of Chicago, 1926.417, artwork 28560, public
domain): blue-violet wall, green window, yellow bed with a red cover and a
pillow, orange-brown floor. No frame, outline, shadow or gradient. The AIC
image was used only as a reference for composition and colour; every pixel
here is drawn from code, nothing is resampled from the photograph.

The approved per-size drawings are copied into `b2.go`, which is the source
for every output below.

Everything is generated by `export.sh`:

| Output | Size | Drawn by |
| --- | --- | --- |
| `assets-src/installer/Paintpane.ico` | 16, 20, 24, 32, 40, 48, 64, 96, 256 (256 stored as PNG) | `icon()` |
| `cmd/spice/spice_windows_amd64.syso` | icon resource `GLFW_ICON` from `assets-src/installer/Paintpane.ico` (`assets-src/installer/winres.json`) | go-winres v0.3.3 |
| `asset/icons/tray.png` | 64: the 16 px drawing, each pixel 4 × 4 | `trayIcon()` |
| `asset/icons/app.png` | 256, window / taskbar / Alt+Tab icon | `icon(256)` |
| `site/assets/icon-256.png` (and a copy for the intro page prototype) | 256, README and intro site | `icon(256)` |
| `site/assets/favicon-32.png` | 32, intro site favicon | `icon(32)` |
| `assets-src/installer/Paintpane.bmp` | 240 × 458, Inno Setup wizard panel: the icon (112 px tile) and the name on cream | `wizardImage()` |
| `asset/images/about_splash.gif` | 600 × 600, ~7.8 s, plays once | `aboutFrames()` |

The exe icon must be the resource named `GLFW_ICON`: GLFW registers its window class with that
icon, and the Windows 11 taskbar draws the app's button from the class icon. Without it the class
gets Windows' generic application icon and the taskbar button shows that, whatever icon the
windows set. Explorer and the Start menu read the same resource.

The other file names are kept from upstream because the code and the makefile refer to them.
The installer files live in `assets-src/installer/` next to `Paintpane.iss`.

## Size tiers (`b2.go`)

Each tier is a list of whole-pixel rectangles copied from the approved
`paintpane-<size>.svg` drawing of that size, drawn back to front and clipped
to the rounded tile.

- **16, 20, 24**: separate pixel drawings for the tray at 100 %, 125 % and
  150 %. Never derive one from another or from the large drawing.
- **32, 40, 48, 64, 96**: the 16, 20 or 24 drawing enlarged by a whole factor
  (×2 or ×4), so block edges stay on whole pixels.
- **256**: the large drawing (tile 224 px, corner radius 40).

Only the tile's rounded corners are partly transparent: each pixel's alpha is
how much of it the tile covers (16 × 16 samples), computed at the target size.

The tray icon is the 16 px drawing enlarged 4× with no further smoothing.
Fyne hands Windows a single image; at 100 % Windows reduces it 64 → 32 → 16
and at 200 % 64 → 32, whole-number steps that give the 16 px drawing back.
At 125 %, 150 % and 175 % the reduction is not whole and the tray image is a
little soft (picking an image per DPI would need changes to the tray code;
not done).

## About animation (old art, kept)

The "About" window animation still shows the earlier pixel-art *Bedroom* in a
gilded frame (owner's decision, 2026-11-15). `scene.go` (the painting as flat
shapes), `frame.go` (the frame), `font.go` (5 × 7 pixel font, also used for
the installer panel) and the extra colours in `palette.go` exist for it;
`export.sh` regenerates the GIF byte for byte unchanged.

## Editing

1. Change a tier in `b2.go` (and the matching `final/*.svg`), or a colour in
   `palette.go`.
2. Run `PREVIEW=/some/dir/preview.png bash assets-src/icon/export.sh` and look
   at the preview sheet (each icon at 1× and zoomed, on dark and light
   taskbar colours). The preview also writes `preview-16.png`, `-20` and
   `-24` at 1× for comparing with the SVGs, and `preview-wizard.png`.
3. Commit the sources together with the regenerated outputs.

This directory is its own Go module (standard library only) so it stays out
of the app's `go vet ./...` / `go test ./...`.
