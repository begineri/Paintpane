Questions

Where do the paintings come from? What about copyright?

From the open-access collections of the museums listed above, downloaded straight from the museums’ own servers. These are images the museums release for free use, mostly of works in the public domain. The tray menu names the work, the artist and the museum. Pictures from wallhaven, Pexels and Wikimedia Commons follow those sites’ own terms.

Is there a free app that sets museum paintings as my Windows wallpaper?

Yes, Paintpane does that. It runs in the tray on Windows 10 and 11, downloads paintings from the open-access collections of museums such as The Metropolitan Museum of Art, the Art Institute of Chicago and the Rijksmuseum, and changes the wallpaper on a schedule.

Do I need to install it? Does it need the internet or collect data?

No installer: Paintpane is a single exe file that runs from any folder. It needs an internet connection to download pictures. It has no account, no analytics and no crash reporting, and sends nothing about you or your PC to the developer. See the privacy page.

How does it relate to Spice?

Paintpane is an unofficial, modified version of Spice. It is not made, endorsed or supported by the Spice project. The two can be installed side by side, but do not run both at once: both change the wallpaper.

Is it free?

Yes, and the source is public. It uses the PolyForm Noncommercial License: you may use, modify and share it, but not for commercial purposes.

Does the filter catch all NSFW content?

No. It relies on collection categories, source ratings and your own marks, so NSFW content is filtered by default, not guaranteed to be.

Does it work with several monitors and the lock screen?

Yes. Each monitor rotates on its own, so each can show a different painting. The lock screen gets a painting too.

Windows says it “protected your PC”. What now?

Windows may show this the first time you run Paintpane. Click More info, then Run anyway.

Does it start with Windows?

Yes, by default. To stop that, turn off Start with Windows in Settings › General.

Is there a macOS version?

Not at the moment. Windows only.
