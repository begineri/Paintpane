隐私说明

适用于 Windows 版观画壁纸：本站下载的便携版和 Microsoft Store 版。最后更新：2026 年 11 月 19 日。

简单说

观画壁纸不收集任何个人数据。没有账号，没有统计，没有广告，也没有崩溃上报。关于你和你电脑的任何信息都不会发给开发者。

它只从你打开的图源下载图片，你的设置和图片都留在你自己的电脑上。

在你电脑上存了什么

内容位置（便携版）位置（Microsoft Store 版）
设置：选了哪些图源和作品集、显示方式、你屏蔽的作品%APPDATA%\fyne\Paintpane\preferences.json%APPDATA%\fyne\PaintpaneStore\preferences.json
下载的图片和作品信息、你的收藏、屏蔽作品的小预览图，以及运行日志（除电脑上的文件路径外，不含个人信息）%LOCALAPPDATA%\PaintpaneWindows 为这个应用单独保留的私有文件夹
你填的 wallhaven 或 Pexels API keyWindows 凭据管理器（你的 Windows 账户受保护的存储），名称是 wallhaven_api_key 或 pexels_api_key；两个版本用的是同一条
当前桌面和锁屏图片的副本，供 Windows 显示不使用图片\Paintpane，只保留正在使用的几张
在浏览器里打开的作品集页面不使用文档\Paintpane，第一次打开时才创建

这些内容都不会离开你的电脑；只有 API key 会发给它所属的网站，不发给别处。

会连接哪些服务器

观画壁纸直接连接下面这些服务器，不发送任何关于你的信息。和访问任何网站一样，它们能看到你的 IP 地址和请求了哪些图片，适用它们各自的隐私政策。

  • 博物馆的开放获取服务器（只连你打开的那几家）：大都会艺术博物馆、芝加哥艺术博物馆、克利夫兰艺术博物馆、荷兰国立博物馆、台北故宫博物院、丹麦国家美术馆、盖蒂博物馆、美国国家美术馆、耶鲁大学艺术馆藏、巴黎市立博物馆联盟，以及它们使用的图片服务器。
  • 维基共享资源（Wikimedia Commons），打开时才连接。
  • wallhaven，打开时才连接。填了 wallhaven API key 的话，每次请求都会带上它。
  • Pexels，打开时才连接。Pexels 需要 API key，只发给 Pexels。
  • GitHub（raw.githubusercontent.com），获取更新后的博物馆作品集清单。
  • GitHub（api.github.com），检查有没有新版本。只有便携版会检查；Microsoft Store 版由 Store 负责更新，不检查。

你在程序里点的链接，例如作品在博物馆网站上的页面、博物馆在地图上的位置，会在你的浏览器里打开。

观画壁纸还在 127.0.0.1（端口 49452）上运行一个本地服务，供它自己的页面使用。其他电脑连不上它，它也拒绝来自网页的请求。

删除你的数据

  • Microsoft Store 版：在“设置 › 应用”里卸载。Windows 会删除应用的私有文件夹。下面几处会留下，可以手动删除：%APPDATA%\fyne\PaintpaneStore（设置文件）、图片\Paintpane、文档\Paintpane，以及你填过的 API key（在“控制面板 › 凭据管理器 › Windows 凭据”里）。
  • 便携版：先在“设置 › 常规”里关掉随 Windows 启动，退出程序，再删除 exe、%LOCALAPPDATA%\Paintpane 和 %APPDATA%\fyne\Paintpane，以及凭据管理器里你填过的 API key。

只想删除下载的图片，可以用“设置 › 高级 › 存储”里的清除缓存。

儿童

观画壁纸不收集任何人的数据，包括儿童。

变更

如果观画壁纸存储的内容或连接的服务器有变化，会在同一个版本里更新本页，并修改顶部的日期。
